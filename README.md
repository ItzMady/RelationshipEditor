[size=6][b]Relationship Editor[/b][/size]

[center]
A simple tool that allows you to edit your relationships with Stardew Valley NPCs.
[/center]

[size=5][b]Features[/b][/size]

[list]
[*] Edit friendship levels with any NPC.
[*] Modify relationship status.
[*] Quickly adjust relationships for testing, debugging, or personal customization.
[*] Supports vanilla NPCs and modded NPCs.
[*] Useful for mod developers, testers, and players who want more control over their save.
[/list]

[size=5][b]How to use[/b][/size]

After installing the mod, use the provided SMAPI commands to manage relationships.

Example:

[code]
relationship_help
[/code]

This will display the available commands.

[size=5][b]Installation[/b][/size]

[list=1]
[*] Install the latest version of [url=https://smapi.io]SMAPI[/url].
[*] Download this mod.
[*] Extract the mod folder into your [font=Courier New]Stardew Valley/Mods[/font] folder.
[*] Launch the game through SMAPI.
[/list]

[size=5][b]Requirements[/b][/size]

[list]
[*] Stardew Valley 1.6+
[*] SMAPI
[/list]

[size=5][b]Compatibility[/b][/size]

Works with vanilla Stardew Valley and most NPC expansion mods.

Multiplayer compatibility has not been tested.

[size=5][b]Known limitations[/b][/size]

This mod directly modifies relationship data. Always keep backups of your saves before making large changes.
